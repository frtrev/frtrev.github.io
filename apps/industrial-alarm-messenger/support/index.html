Support

Industrial Alarm Messenger

For product questions, installation assistance, privacy inquiries, or issue reports, email ftrevino@yahoo.com.

Include with a support request

  • App version and Android version
  • Phone manufacturer and model
  • Whether the gateway foreground notification was visible
  • Relevant timestamps and exported audit entries
  • SIM and carrier status without exposing telephone numbers, API keys, or administrator PINs
Do not email secrets. Never send an API key, administrator PIN, keystore, signing password, or unredacted production recipient list.
