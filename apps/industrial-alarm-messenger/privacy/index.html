Privacy Policy

Industrial Alarm Messenger is published by Francisco Trevino under NeoTheOne. It is an offline industrial utility. It does not create accounts, show advertising, include analytics, or transmit data to a developer-operated cloud service.

Information processed

The app stores administrator-created recipient names, roles, telephone numbers, group configuration, network and security settings, request identifiers, source IP addresses, alarm text, SMS attempt results, SIM identifiers, timestamps, and security failures.

Purpose

This information is used only to authenticate local alarm requests, route alarms to configured recipients, send SMS notifications, show operational status, prevent replay attacks, and maintain an administrator-visible audit history.

Storage and disclosure

Information is stored locally in the app’s private application storage on Android or iOS. Alarm text and recipient telephone numbers are provided to the selected mobile carrier when Android sends an SMS or an approved iPhone deployment uses Apple’s Critical Messaging API. Data is otherwise disclosed only when an administrator explicitly exports audit logs or when facility-controlled device-management or backup software accesses application data.

Permissions

  • SMS on Android: sends requested industrial alarm notifications.
  • Phone and SIM state on Android: displays SIM readiness and supports administrator selection on dual-SIM devices.
  • Network: accepts authenticated TCP connections on the facility’s local network.
  • Android notifications and foreground service: visibly keeps an administrator-started gateway active while its interface is backgrounded or the screen is off.
  • Android wake and Wi-Fi locks: maintain CPU and facility Wi-Fi availability while the gateway is running.
  • Critical Messaging on iOS: requests authorization for each enabled recipient and sends critical SMS only in Apple-approved deployments.
  • Local Push Connectivity on iOS: lets an Apple-approved provider receive local alarm events while the main app is backgrounded.

The app does not read contacts, call logs, incoming messages, photos, microphone data, camera data, or device location.

Retention and deletion

Audit and configuration data remains on the device until an administrator clears it, application data is deleted, or the app is uninstalled. The deploying organization controls exported copies and their retention.

Security and organizational responsibility

The app uses an API key, request identifiers, timestamp validation, source-network restrictions, and an administrator PIN. The deploying organization is responsible for recipient authorization, lawful SMS use, device and network security, retention, and access controls.

Children’s privacy

This app is intended exclusively for adult professionals in industrial and engineering environments and is not directed to children.

Changes and contact

This policy may be updated when application behavior or legal requirements change. Questions or privacy requests may be sent to ftrevino@yahoo.com.
