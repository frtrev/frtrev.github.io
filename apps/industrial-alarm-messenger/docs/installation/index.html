Commissioning guide

Installation

Device requirements

  • Android 7.0 or newer phone with telephony/SMS support and an active SIM
  • Static DHCP lease or reserved facility Wi-Fi address
  • Private, firewalled automation network
  • Supervised, preferably UPS-backed power

Commissioning checklist

  1. Install the Google Play release on the dedicated phone.
  2. Disable battery optimization for the app in Android system settings.
  3. Grant SMS, phone/SIM, and notification permissions.
  4. Open Administrator, use the initial PIN, and change it immediately.
  5. Regenerate the API key before production use and copy it only to authorized clients.
  6. Create groups and recipients using E.164 telephone format such as +15551234567.
  7. Restrict allowed CIDRs to specific automation subnets.
  8. Assign a stable local address and document the TCP port.
  9. Start the gateway and confirm its persistent Android notification.
  10. Send ping, then a non-critical test alarm; verify SMS behavior and audit records.
  11. Export and retain the commissioning log.

Hardening

  • Isolate the phone and trusted clients on a dedicated VLAN.
  • Block access from guest Wi-Fi, user networks, and the public Internet.
  • Rotate the API key after personnel or equipment changes.
  • Store the administrator PIN in the facility credential vault.
  • Restrict physical access and enable Android encryption and screen lock.

Continuous operation

The persistent Industrial Alarm Gateway running notification indicates that the foreground service is active. Device manufacturers may still impose power restrictions. Validate background and screen-off behavior on the exact managed device. Force-stopping the app stops the gateway; after every restart, confirm its running state.

Review the safety disclaimer before commissioning.
